# VORTEX — Predictive Maintenance System

VORTEX is a predictive maintenance platform built for DAIICT Hackout 2026, designed to help detect equipment issues before they happen using data-driven monitoring and analysis.

## 🚀 Features

- Predictive maintenance dashboard
- Real-time monitoring and alerts
- Backend powered by Supabase (database + auth)
- Presentation materials included for project walkthrough

## 📁 Project Structure

├── src/ # Core application source code
├── public/ # Static public assets
├── scripts/ # Utility/automation scripts
├── supabase/ # Supabase config, schema, and database functions
├── presentation_assets/ # Slides, images, and materials for presentation
├── VORTEX Predictive Maintenance Presentation # Project presentation
└── node_modules/ # Installed dependencies


## 🛠️ Tech Stack

- **TypeScript** — application logic
- **JavaScript** — supporting scripts
- **PL/pgSQL** — Supabase database functions
- **CSS** — styling
- **Supabase** — backend, database, and authentication

## 📖 Getting Started

1. Clone the repository:
```bash
   git clone https://github.com/harryvaishnani/DAIICT-Hackout-2026.git
   cd DAIICT-Hackout-2026
```
2. Install dependencies:
```bash
   npm install
```
3. Set up Supabase environment variables (create a `.env` file with your Supabase URL and API key).
4. Run the project:
```bash
   npm run dev
```
